WARUNG NASI AYAM RINDU — PWA POS

Versi ini ialah PWA daripada POS meja yang sedia ada.

CIRI:
- Boleh dipasang sebagai ikon/app pada telefon melalui Chrome apabila dihoskan menggunakan HTTPS.
- Selepas dibuka dan cache selesai, POS boleh digunakan offline.
- Data jualan/menu/meja disimpan secara tempatan pada peranti tersebut.
- Tiada sync automatik dengan PC.
- Backup/Restore masih tersedia.

PENTING:
- Fail ZIP ini bukan link PWA yang boleh terus dipasang. Untuk pemasangan sebagai PWA, fail perlu diletakkan pada hosting HTTPS.
- Selepas ada URL HTTPS, buka URL itu pada Chrome telefon > menu ⋮ > Add to Home screen / Install app.
- Jangan padam data browser atau uninstall app tanpa backup jika mahu mengekalkan data jualan.
